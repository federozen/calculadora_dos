# Calculadora LPF Lite 1.0.1 — Single File

Versión mínima para Streamlit Cloud. No usa paquetes internos del proyecto: toda la lógica vive en `app.py`.

## Archivos

- `app.py`: aplicación + datos + parser TyC + motores + simulación.
- `requirements.txt`: dependencias.
- `.streamlit/config.toml`: configuración visual.

## Deploy en Streamlit Cloud

1. Subir **todo el contenido de esta carpeta** a la raíz del repositorio.
2. Main file path: `app.py`.
3. No requiere secrets.

La versión visible debe ser **1.0.1**.
